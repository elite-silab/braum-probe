# Braum UI 视觉与交互规范

> 版本：v2.0 · 更新：2026-07-25

## 1. 设计原则

- **状态优先**：在线、离线、暂停、待安装和数据过期必须一眼可辨。
- **数据诚实**：未知显示 `--`，不能用 0 伪装；位置注明来自配置；资源注明采集时间。
- **高密度但可扫描**：等宽数字、短标签、统一资源条和明确分组。
- **渐进披露**：总览看结论，详情看趋势，管理后台处理配置与密钥。

## 2. 颜色语义

| 语义 | 颜色 | 用途 |
|---|---|---|
| 正常 | Emerald | 在线、资源低于阈值、成功 |
| 注意 | Amber | 暂停、75%–90%、部分异常 |
| 严重 | Red | 离线、失败、资源 >= 90% |
| 等待/未知 | Slate | 待安装、无数据、次要信息 |
| 品牌/操作 | Blue | 链接、主按钮、趋势主线 |

所有状态同时包含文字或图标，禁止只靠色差传达。

## 3. 组件

- 卡片：`rounded-2xl`、1px 边框、轻阴影；Hover 最多上移 2px。
- 指标数字：等宽字体，保留单位，精度统一（资源 1 位、可用率 2 位）。
- 资源条：高度 6px；0–75% 绿、75–90% 黄、90–100% 红。
- 状态徽章：圆点 + 文案；待安装与离线是不同状态。
- 安装命令：深色代码块、可选择、自动换行、独立复制按钮和令牌过期警告。
- 弹窗：标题、正文、主次操作清晰；危险操作使用红色并要求二次确认。

## 4. 页面状态

| 状态 | 规范 |
|---|---|
| 初次加载 | 骨架与最终布局同形，减少 CLS |
| 后台刷新 | 保留内容，仅刷新按钮旋转并禁用 |
| 空数据 | 说明原因并给出下一步，不用“系统正常”替代 |
| API 错误 | `role=alert`、友好文案、重试；不显示堆栈 |
| Agent 离线 | 保留最后数据并突出采集时间，不把旧数据当实时 |
| 待安装 | 安装引导，不显示 0% 资源 |

## 5. 响应式与无障碍

- `<640px` 单列卡片和底部导航；表格允许横向滚动或转卡片。
- `640–1024px` 双列；桌面三列资源卡片。
- 点击目标至少 44×44px；键盘焦点清晰；表单有可见 label。
- 趋势图提供 `aria-label`；纯装饰 SVG 使用 `aria-hidden`。
- 亮/暗主题正文对比度达到 WCAG AA。

## 6. 主题

保留 Braum 蓝、樱、星海、翠灵主题，但主题只改变品牌与表面色，不改变绿/黄/红状态语义。主题使用 CSS 变量和 `data-theme`，暗色偏好存储在 `localStorage`，首屏内联初始化避免闪烁。
