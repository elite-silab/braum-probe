# ADR-0001：采用 Workers 控制面与 VPS Agent 数据面

## 状态

已接受（2026-07-25）

## 背景

Braum 需要提供类似哪吒探针、Komari 的 VPS 在线监控体验，包括主机资源、网络质量、远程探测和后续远程终端。Cloudflare Workers 运行在隔离的边缘运行时中，不能直接读取任意 VPS 的 CPU、内存、磁盘、进程或终端，也不能把中心 Cron 创建的逻辑配置当成真实的地理探测节点。

项目同时需要保留 Cloudflare 原生部署的低运维优势：API 与 Web 都运行在 Workers，配合 D1、KV，不引入必须自行维护的中心服务器。

## 决策

采用控制面/数据面分离的混合架构：

- Cloudflare Workers 是唯一 API 与调度控制面，负责用户鉴权、节点注册、配置下发、指标接收、告警评估和审计。
- 每台被监控 VPS 安装一个开源的 Braum Agent。Agent 主动通过 HTTPS 连接 Workers，不要求 VPS 开放入站端口。
- 管理员为节点生成 15 分钟有效、仅可使用一次的注册令牌。Agent 使用注册令牌换取节点专属长期密钥；D1 只保存密钥摘要。
- Agent 周期上报主机信息和资源指标，并从心跳响应获取该节点关联的 HTTP/DNS 探测任务。
- HTTP/DNS 探测在 Agent 所在 VPS 上执行，结果由 Agent 上报；Cloudflare Cron 不再伪装成节点执行探测或更新节点心跳。
- 节点是否在线只由最近 Agent 心跳决定。
- 远程终端作为独立高风险通道设计，使用短时会话票据、再次授权、完整审计和独立于心跳密钥的会话协议。

## 后果

### 正面

- 节点位置、资源指标和网络延迟都来自真实 VPS，不再存在逻辑节点冒充全球节点的问题。
- VPS 无需开放 Agent 端口，适合 NAT、防火墙和动态 IP 环境。
- 控制面仍然是无服务器架构，部署和维护成本较低。
- 一次性注册令牌与摘要存储减少安装命令泄漏后的长期风险。
- Agent 可独立升级，并可逐步增加进程、容器和 GPU 指标。

### 负面

- 项目新增 Go Agent、跨平台构建、发布制品和升级兼容性维护。
- D1 时序写入量随节点数和上报频率增长，需要保留、聚合与限额策略。
- Agent 长期密钥仍是高价值凭据，需要支持轮换、吊销和速率限制。
- 远程终端需要 WebSocket/中继能力，其安全和运行成本明显高于普通监控。

### 中性

- Workers 自身仍可执行控制面健康检查，但这类检查必须标记为“控制面探测”，不能算作 VPS 节点数据。
- 节点表保留地理信息作为管理员声明的资产属性；Agent 上报的 hostname、OS 和网络信息独立存储。

## 备选方案

### 纯 Workers 无 Agent

适合公开网站状态页和 HTTP/DNS 可用性检查，但无法实现 VPS 资源监控和远程终端，不满足产品目标。

### Workers 直接 SSH 每台 VPS

要求开放入站 SSH、集中保存高权限私钥，并受 Workers 连接和执行模型限制，攻击面和运维风险不可接受。

### 自建中心服务替代 Workers

可以简化长连接和时序数据库使用，但失去 Cloudflare 原生、低运维的产品优势。远程终端规模增长后可重新评估专用中继，而不是现在引入。

## 安全约束

- 所有 Agent 请求必须使用 HTTPS。
- 注册令牌默认 15 分钟过期、成功使用后立即失效。
- D1 不保存注册令牌或 Agent 密钥明文。
- Agent 上报接口限制请求体大小、指标范围、结果数量和请求频率。
- 安装脚本不得在日志中输出长期 Agent 密钥。
- 删除或重新注册节点必须吊销旧 Agent 密钥。
- 远程终端不得直接复用 Agent 心跳接口、JWT 或永久节点密钥作为会话票据。
