# 首页节点卡片信息密度设计

## 目标

管理员和访客不进入详情页，也能快速判断每台 VPS 的系统环境、资源占用、流量、实时网络和运行时长。交互参考 Komari 的信息密度，但沿用 Braum 的状态色、主题和卡片语言。

## 布局

卡片采用紧凑运维仪表盘布局：顶部为节点与在线状态，随后展示完整 Linux 发行版及架构；CPU、内存、磁盘使用横向进度条，其中内存和磁盘同时显示百分比与容量；网络区按“总流量、实时网络、运行时间”纵向排列；底部保留探测延迟、24 小时可用率、负载、趋势和采集时间。

总流量明确使用“本次开机”口径。项目尚无计费周期和套餐流量配置，因此首页不虚构 Komari 示例中的 `Max` 或使用率；以后增加流量配额时，应先定义计费周期、重启累计和清零规则。

## 数据

Agent 从 `/etc/os-release` 读取 `PRETTY_NAME`。节点列表 API 同时取得最新与前一条网络累计计数器，复用共享算法计算采样区间平均速度；计数器回退时速度归零。API 不增加 D1 写入。

## 响应式与验证

- 桌面保持三列卡片，平板两列，手机单列。
- 手机筛选工具栏使用四等分控件，不发生竖排文字或横向溢出。
- 验证完整 Debian 名称、容量、上下行速率和精确运行时间均可见。
- 运行 API/Go 测试、TypeScript、ESLint 和 Worker 生产构建，并在真实本地页面检查桌面和 390px 手机宽度。
