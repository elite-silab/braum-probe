# 管理员账号安全与修改密码设计

## 目标

为已登录用户提供轻量、安全的自助改密能力，不复用 Owner 可管理其他用户的通用用户更新接口。

## 交互

- 在管理后台“系统设置”页面增加独立的“账号安全”板块。
- 账号安全板块展示当前账号信息，并要求填写当前密码、新密码和确认密码。
- 新密码长度限制为 12–128 个字符，且不能与当前密码相同。
- 修改成功后清除当前浏览器中的访问令牌和刷新令牌，返回登录页并显示成功提示。

## 接口与安全边界

- 新增 `POST /api/v1/auth/change-password`。
- 请求必须携带有效访问令牌，账号必须处于启用状态。
- 服务端重新校验当前密码，只修改令牌所属用户的密码哈希。
- 审计日志只记录“修改密码”事件，不记录当前密码、新密码或密码哈希。
- 改密接口使用独立限流，降低密码猜测风险。

## 验证

- API 自动测试覆盖：未登录、当前密码错误、新密码格式无效、新旧密码相同、成功更新。
- 前端通过 TypeScript、ESLint、生产构建和移动端/桌面端页面检查验证。
