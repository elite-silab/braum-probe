# 管理后台侧边栏优化设计

## 方向

采用克制、专业的“精致控制轨”风格。保留现有菜单和主题系统，不引入新的页面层级，也不使用大面积装饰动画。

## 结构

- 品牌区展示 Braum Probe 与轻量监控定位，Logo 使用主题色光晕强化识别。
- 导航分为“工作台”“监控中心”“运营与系统”三组，降低连续七个入口的阅读压力。
- 统一使用细线 SVG 图标，替换风格和尺寸不一致的 Emoji。
- 当前页面使用主题色指示条、柔和底色和图标强调形成明确激活态。
- 底部说明运行于 Cloudflare Workers，并保留返回前台入口。

## 响应式交互

- 桌面端固定为 256px 展开态，不提供折叠按钮，避免布局跳动并始终保留完整菜单信息。
- 移动端继续使用遮罩抽屉，正文保持全宽；抽屉宽度和点击区域适配触屏。
- 子页面路径继续高亮其所属一级菜单。

## 验证

- 组件测试确认产品标识和导航分组不会在后续改动中丢失。
- 本地检查桌面固定展开态、无折叠入口、当前页激活态以及移动抽屉。
- 最后运行全量测试、类型检查、Lint 和 Cloudflare 生产构建。
