# 单 Cron 调度器设计

## 目标

将原有五条 Cloudflare Cron Trigger 合并为一条 `* * * * *`，降低免费套餐的触发器占用，同时保持用户配置的一分钟 Agent 采集与节点离线判定频率不变。

## 调度规则

- 每分钟：检查 Agent 心跳并标记离线节点。
- UTC 偶数分钟：评估资源、心跳和探测告警。
- UTC 每小时整点：生成上一完整小时的聚合统计。
- UTC 02:00：生成上一完整 UTC 日的聚合统计。
- UTC 03:00：清理过期指标、探测结果、聚合、审计日志和注册令牌。

调度使用 Scheduled Event 的 `scheduledTime`，不依赖 Worker 实际开始执行的本地时间。每项任务独立捕获异常，避免聚合或清理失败阻断节点心跳检查。

## 验证

- 单元测试覆盖普通分钟、偶数分钟、UTC 02:00 和 UTC 03:00。
- 验证 Wrangler 最终只声明一条 Cron Trigger。
- 运行全量测试、类型检查、Lint 和生产构建。
