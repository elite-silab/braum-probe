# Braum 前端功能与交互设计

> 版本：v2.3 · 更新：2026-07-27

## 1. 体验目标

公共页面需要在十秒内回答三个问题：

1. 哪些 VPS 正常、离线、暂停或尚未安装 Agent？
2. 当前 CPU、内存、磁盘、网络和运行时间是否异常，数据是什么时候采集的？
3. 从每台 VPS 到监控目标的延迟和可用率如何？

所有指标必须来自真实 Agent 上报或 Agent 本地探测。地理位置默认由 Agent 请求的 Cloudflare 信息识别，允许管理员手动修正，但不能推导为 Cloudflare 实际执行位置。

## 2. 信息架构

| 页面 | 路由 | 核心内容 |
|---|---|---|
| 基础设施总览 | `/` | 全局健康、完整节点目录、探测摘要、近期事件 |
| VPS 详情 | `/node/:id` | 当前资源、24h 趋势、主机信息、探测历史、可用率 |
| 探测历史 | `/history` | 按 VPS 与时间范围筛选 Agent 本地探测结果 |
| 事件公告 | `/incidents` | 故障、维护和恢复时间线 |

桌面端使用顶部导航；移动端使用固定底部导航。节点目录直接位于总览页，点击卡片进入 `/node/:id`，不再提供低使用率的全球地图页面。

## 3. 总览页面

### 3.1 全局健康条

- 全部已注册节点在线：绿色“所有已注册节点运行正常”。
- 存在离线/暂停/待安装节点：琥珀色“部分节点需要关注”。
- 无节点：明确引导管理员添加 VPS，而不是显示“系统正常”。
- API 获取失败：保留上次数据，显示错误和重试按钮。

### 3.2 节点目录与 VPS 卡片

总览页是节点目录的唯一入口，不再维护信息不完整的第二套卡片。目录保留状态、地区筛选和排序，并在桌面与移动端使用相同的信息结构。

每张卡片展示：

- 节点名称、配置城市/国家、完整 Linux 发行版、发行版家族/架构、Agent 版本。
- 待安装、在线、离线或暂停状态。
- CPU 百分比；内存、磁盘同时显示百分比和“已用 / 总量”，保留阈值色。
- 本次开机累计下载、上传、总流量，最近两次采样计算的上下行速度，以及精确到秒的运行时间。
- WebSocket 实时控制通道是否连接；该状态与心跳判定的节点健康状态分开显示。
- 1 分钟负载、24h 平均探测延迟和可用率。
- 延迟迷你趋势与“多久前采集”的新鲜度。

这些日常判断信息必须在首页直接可见，详情页只承载趋势和更深的主机信息。没有资源样本时不得展示 `0%`，应展示“尚未采集”以及安装或排障提示。

### 3.3 筛选与刷新

- 管理页保留名称搜索和状态筛选；地区信息自动识别，不把它作为新增节点前置条件。
- 默认通过同源 WebSocket 接收变化事件并重新读取 API；30 秒静默刷新作为降级保护。页面不可见时暂停，重新可见时立即刷新并重连。
- 手动刷新只禁用刷新按钮并保留现有内容，不切回整页骨架屏。

## 4. VPS 详情

- 顶部：节点 ID、Agent 注册/在线状态、hostname、区域、位置和采集间隔。
- 资源区：CPU、内存、磁盘、负载卡片及 24h CPU/内存趋势。
- 网络与运行：相邻采样计算的实时上下行速率、本次开机累计流量、TCP 连接、进程数、运行时间和 24h 网速趋势；计数器重置不得产生负速率。
- 主机信息：发行版、架构、内核、CPU、核心数和虚拟化类型。
- 探测区：目标名称、成功状态、延迟、HTTP 状态码、时间。
- 可用率：24h/7d/30d；无数据时显示 `--`，不等同于 0%。

## 5. 探测历史

前端把 24h/7d/30d/90d 转换为 API 的 `start_time`，而不是发送不存在的 `time_range` 参数。结果显示节点名与目标名，失败数据的空延迟保持 `--`。

## 6. 状态与无障碍

管理后台首次使用遵循渐进披露：基础监控只要求“添加节点 → 安装 Agent”；目标探测、告警和高级字段按需展开。目标创建只要求地址，告警规则优先选择推荐模板，通知渠道不得暴露 JSON 配置编辑器。

每个数据组件必须覆盖：

- 初次加载骨架。
- 有数据的正常状态。
- 后台刷新状态。
- 空数据与待安装状态。
- Agent 离线或数据过期。
- API 错误和可操作的重试。

键盘焦点可见；状态不能只依赖颜色；错误容器使用 `role="alert"`；趋势 SVG 提供可读标签或作为装饰隐藏；正文对比度满足 WCAG AA。

## 7. 性能目标

| 指标 | 目标 |
|---|---|
| LCP | < 1.5s（正常边缘缓存） |
| CLS | < 0.1 |
| 初始交互 JS | < 200KB gzip |
| 实时与轮询 | WebSocket 指数退避重连；页面隐藏时不请求；保留 30 秒降级轮询 |
| 节点列表 | 单次最多 100 条，规模增长后启用分页/虚拟列表 |
