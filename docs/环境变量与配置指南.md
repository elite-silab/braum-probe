# Braum 环境变量与配置

> 版本：v3.0 · 更新：2026-07-27

## 配置原则

- 本地开发只使用仓库根目录 `.env`。
- 生产普通配置只使用根目录 `wrangler.jsonc`。
- 生产密钥只填写到 Cloudflare Worker 的 Variables and Secrets。
- 网站和 API 同源，不存在 `PUBLIC_API_URL` 或 CORS 白名单。
- 不创建 `.dev.vars`、`apps/web/.env` 或 `apps/api/.env`。

## 本地 `.env`

在文件管理器中复制 `.env.example`，将副本改名为 `.env`，然后直接编辑。

| 变量 | 新手是否修改 | 说明 |
|---|---|---|
| `ADMIN_INITIAL_PASSWORD` | 建议修改 | 本地首次登录密码 |
| `JWT_SECRET` | 通常不用 | 本地 Access Token 签名 |
| `JWT_REFRESH_SECRET` | 通常不用 | 本地 Refresh Token 签名 |
| `ENCRYPTION_KEY` | 通常不用 | 本地通知配置加密 |
| `AGENT_API_URL` | 调试 Agent 时 | 默认 `http://localhost:3000` |
| `AGENT_RELEASE_BASE_URL` | 调试安装时 | Agent Release 下载目录 |
| `TELEGRAM_BOT_TOKEN` | 可选 | Telegram 默认机器人 Token |

`.env.example` 中的安全值只能用于本地，不能复制到生产环境。

## 生产普通配置

根目录 `wrangler.jsonc` 是唯一 Wrangler 配置：

| 配置 | 说明 |
|---|---|
| `name` | Worker 名称，默认 `braum-probe` |
| `APP_VERSION` | 健康检查显示的版本 |
| `AGENT_API_URL` | Agent 访问的 Worker HTTPS 地址 |
| `AGENT_RELEASE_BASE_URL` | Agent 二进制和校验文件目录 |
| D1 `database_id` | `DB` 绑定使用 |
| KV `id` | `CACHE` 绑定使用 |
| `triggers.crons` | 告警、心跳、聚合和清理计划 |
| `REALTIME` Durable Object | WebSocket 连接中心，由部署自动创建，无需填写 ID |

`AGENT_API_URL` 必须从 VPS 可访问，生产环境使用 HTTPS，末尾不要添加 `/`。

## 生产密钥

进入 Cloudflare Dashboard → `braum-probe` → Settings → Variables and Secrets：

| Secret | 必填 | 说明 |
|---|---|---|
| `JWT_SECRET` | 是 | 随机至少 32 字节 |
| `JWT_REFRESH_SECRET` | 是 | 与 JWT_SECRET 不同 |
| `ENCRYPTION_KEY` | 是 | AES-GCM 通知配置加密密钥 |
| `ADMIN_INITIAL_PASSWORD` | 首次部署 | 初始 Owner 密码 |
| `TELEGRAM_BOT_TOKEN` | 按需 | Telegram 默认 Token |

不要把生产密钥写入 `.env.example`、`wrangler.jsonc`、截图、聊天记录或 Git 历史。

## Cloudflare Bindings

| Binding | 类型 | 作用 |
|---|---|---|
| `DB` | D1 | 节点、指标、探测、告警和审计 |
| `CACHE` | KV | 登录接口的低频分布式限流；额度异常时自动降级，不影响 Agent 上报 |
| `ASSETS` | Workers Assets | Next.js 静态资源 |
| `REALTIME` | Durable Object | Agent 与状态页的休眠 WebSocket 连接 |

四个绑定属于同一个 Worker。`REALTIME` 的 class 和 migration 已在 `wrangler.jsonc` 中声明；普通用户不要删除，也不需要在 Cloudflare 控制台手工创建资源。

## Agent 配置

VPS 安装后的配置位于 `/etc/braum-agent/config.json`，权限为 `0600`：

```json
{
  "server": "https://braum-probe.example.workers.dev",
  "node_id": "节点ID",
  "agent_secret": "仅本机保存，数据库无明文",
  "interval": 60
}
```

首次注册成功后，Agent 会删除一次性令牌并写入节点独立密钥。不要把一个节点的配置复制到另一台 VPS。

Agent 会从 `server` 自动把 `https://` 转换为 `wss://` 并连接 `/api/agent/v1/ws`。配置文件不增加 WebSocket URL、端口、证书或重连参数。

## 检查清单

- 仓库中没有真实 `.env` 或 `.dev.vars`；
- 根目录只有一份 `wrangler.jsonc`；
- D1 与 KV ID 属于当前 Cloudflare 账号；
- `AGENT_API_URL` 与实际 Worker 地址一致；
- 三个生产安全密钥互不相同；
- GitHub Agent Release 可以公开下载。

完整网页操作见 [小白部署指南](小白部署指南.md)。
